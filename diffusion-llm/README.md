# diffusion-llm — diffusing stream companion

Компаньон к ролику «Диффузионная LLM: 1000+ токенов в секунду (Mercury 2.5)»: два хука
и демо, которое ставит два стрима рядом — привычные OpenAI-дельты против diffusing-стрима
с флагом `diffusing: true`.

## В чём суть

Обычный OpenAI-стрим присылает **дельты**: `delta: "при"` → дописал в буфер → `delta: "вет"` → дописал.

Diffusing-стрим (Mercury с `diffusing: true`) присылает **полные состояния**: каждое
событие содержит весь текущий текст — от шумного черновика к финалу. Поэтому буфер надо
**замещать целиком**, а не дописывать. Склеивание дельт здесь даёт «лестницу из черновиков» —
в демо это отдельная красная панель.

```
data: {"delta": "Диффузионная "}                        ← дельта: buffer += chunk
data: {"text": "▒иффу▒ионная мо▒ель ▒енерирует…"}      ← состояние: buffer = chunk
data: {"text": "Диффузионная модель генерирует…"}       ← чище
data: {"text": "Диффузионная модель генерирует ответ целиком"}  ← финал
```

## Состав

- `src/useDiffusing.ts` — хук для diffusing-стрима: единственный источник правды — `text`,
  обновляется **заменой**. ~70 строк с типами и комментариями.
- `src/useDeltaStream.ts` — привычный стрим дельт для сравнения: буфер **дописывается**.
- `src/App.tsx` — две панели side-by-side + баг-панель «concat вместо replace».
- `mock-server.mjs` — один эндпоинт `/chat`: без флага отдаёт дельты, с `diffusing: true` —
  полные состояния. Работает офлайн, без API-ключа.

## Запуск

```bash
npm install
npm run mock   # терминал 1: mock-стрим на :8787
npm run dev    # терминал 2: приложение на :5173 (проксирует /chat в mock)
```

Быстрая проверка контрактов без браузера:

```bash
npm run check  # дельты складываются в точный финал; diffusing замещает буфер,
               # шум монотонно убывает; баг-склейка += раздувает текст в 7 раз
```

## Живой Mercury API

Демо умеет ходить в настоящий API через dev-прокси — ключ живёт только в окружении
dev-сервера, в браузер не попадает:

```bash
# Inception Labs
MERCURY_URL=https://api.inceptionlabs.ai MERCURY_KEY=sk-… npm run dev

# OpenRouter (единый биллинг)
MERCURY_URL=https://openrouter.ai MERCURY_KEY=sk-or-… MERCURY_MODEL=inception/mercury-2.5 npm run dev
```

Источник показан в шапке приложения. Хук парсит оба формата событий: `{"text": …}` (мок)
и OpenAI-совместимый `choices[0].delta.content` (живой API). Хук сам по себе API-агностичен:

```ts
const { text, send } = useDiffusing({
  url: "https://ваш-прокси/v1/chat/completions",
  model: "mercury-2.5",
});
```

Тело запроса — OpenAI-совместимое, отличие одно: `diffusing: true`. Напрямую из браузера
к Inception не пойти (CORS) — ходите через свой прокси или dev-прокси из `vite.config.ts`.

## Замечания по рендеру

- Промежуточные состояния содержат шум-глифы (`▒▓█░`) — это нормально, к финалу они исчезают.
- Чтобы текст не «прыгал», анимируйте контейнер, а не текст; на длинных ответах режьте
  рендер на предложения и обновляйте только хвост.
